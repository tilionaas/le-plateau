Installer Le plateau

macOS 12 ou plus récent. Pour savoir quelle version prendre : menu → À propos de ce Mac. « Puce Apple M… » : la version Mac. « Processeur Intel » : la version Mac Intel.

  1. Ouvre Le-plateau.dmg, puis glisse Le plateau sur le dossier Applications.
  2. Ouvre Le plateau depuis Applications. L'app s'ouvre dans ton navigateur.

Si rien ne se passe quand tu ouvres l'app

Tu l'as probablement ouverte depuis la fenêtre du téléchargement (celle où il y a l'icône Le plateau à côté du dossier Applications). Elle ne peut pas démarrer de là. Glisse l'icône sur Applications, ferme cette fenêtre, puis ouvre Le plateau depuis ton dossier Applications (Finder → Applications).

Si le Mac bloque l'app (macOS 15 Sequoia et plus récents)

La première fois, macOS peut dire qu'il ne peut pas vérifier l'app, parce qu'elle ne vient pas de l'App Store. Ça ne se fait qu'une fois :

  1. Dans la fenêtre d'avertissement, clique Terminé. Surtout pas « Placer dans la corbeille ».
  2. Ouvre le menu (en haut à gauche) → Réglages Système → Confidentialité et sécurité.
  3. Descends jusqu'à la partie Sécurité. Tu y vois « Le plateau a été bloqué… ». Clique Ouvrir quand même.
  4. Confirme avec ton mot de passe ou Touch ID, puis clique encore Ouvrir quand même.
Le bouton « Ouvrir quand même » reste environ une heure après la tentative d'ouverture. Si tu ne le vois pas, rouvre l'app une fois (étape 1), puis reviens dans les Réglages.

Sur macOS 14 Sonoma et plus anciens

Dans Applications, fais un clic droit (ou Ctrl + clic) sur Le plateau → Ouvrir → Ouvrir.

Si macOS dit que l'app est « endommagée »

Ouvre Terminal (Applications → Utilitaires), colle cette ligne, appuie sur Entrée, puis rouvre l'app : xattr -dr com.apple.quarantine "/Applications/Le plateau.app" Elle retire seulement l'étiquette « téléchargé d'internet » de l'app. Rien d'autre ne change.

Ensuite

  • Tes données (campagnes, clips, vidéos) vont dans le dossier Le plateau de ton dossier personnel. Elles ne quittent pas ton Mac.
  • Sur un Mac Intel, les sous-titres automatiques sont plus lents à fabriquer.
  • L'IA : dans l'app, clique la petite pastille de version à côté du nom, puis Connecter Claude. Il faut un abonnement Claude.
  • Les sous-titres automatiques : même panneau, Activer (un téléchargement de 570 Mo, une seule fois).
  • Les mises à jour arrivent d'elles-mêmes : l'app te les propose.
  • Pour fermer : même panneau, Quitter.
